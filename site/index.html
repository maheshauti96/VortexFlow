Privacy policy ↗
The one network request, in source ↗
How do mouse and keyboard activation work?

Tap to leave the switcher open, or hold and release to switch. Choose a mouse button or keyboard shortcut in Settings. The previous window is preselected, using per-window recency.

What can I pin?

Links, apps, and keyboard shortcuts can be pinned into the spiral and reordered by dragging. Separately, you can choose running apps to always show first; their windows retain recency ordering.

Which windows and tabs can I find?

Search by title, app, site, or URL path. Supported tab providers include Chrome, Safari, Edge, Brave, Arc, Comet, Chromium, and Apple Terminal. If windows and tabs do not match, installed applications can appear. Web and assistant actions open their provider sites.

What permissions do I need?

Grant only the permissions for the features you want. Icon View needs no Screen Recording. Strip, Grid, and List can show window previews; Spiral and Circular use icons. Permission guide.

What about private windows and screen sharing?

Private windows use the browser's icon; their site icon is not fetched. You can opt the overlay out of screenshots, but behavior depends on macOS and the recording app. Check your setup before sharing.

Is it really free?

Yes. VortexFlow is open source under the MIT license. There is no paid tier, no trial, no license key, and no account. Download the build or compile it yourself. Either way it is the same code.

Why does macOS say the developer can't be verified?

That sheet is expected. VortexFlow is open source. Apple has not notarized the download, so macOS asks you to confirm once. System Settings → Privacy & Security → Open Anyway. Or build from source and the sheet never appears. The one click.

Where should I download it from?

The disk image on this site, or build it from the public source. VortexFlow asks for Accessibility, Input Monitoring, and Screen Recording, exactly the permissions a tampered copy would need. The download page lists the SHA-256 of the image.

How can I help?

Use it on a real desk and report what breaks, especially mice and browsers we have not seen. Pull requests are welcome; the codebase is plain Swift with a large test suite. Where to start.
