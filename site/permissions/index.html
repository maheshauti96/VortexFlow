macOS permissions

Grant only what you want. The rest still runs.

VortexFlow asks for three permissions on first launch and explains each one. Automation is asked later, the first time tab search or site icons need it. Reopen the setup window any time from the menu bar icon.

PermissionWhat it doesWithout it
Input Monitoring Noticing your mouse button, including extra buttons most utilities never see Keyboard shortcut only
Accessibility Listing individual windows, and raising the exact one you pick Whole apps come forward instead of specific windows
Screen Recording Live window thumbnails from ScreenCaptureKit Cards show large app icons instead (Icon View)
Automation Tab search and site icons, for browsers you actually use Windows still switch; tabs are not searchable and site icons are not fetched

The purple indicator

While Screen Recording is granted and thumbnails refresh, macOS may show that VortexFlow is accessing the screen. That is the system privacy indicator, not an upload. Thumbnails are not saved. If you would rather not see it, use Icon View. It needs no Screen Recording.

Grant from the app, not the plus button

macOS records privacy permissions against an app's code identity. Adding VortexFlow with the + button in System Settings is less reliable than letting the setup window ask the system directly. If a row never appears, leftover records from an old build are usually why; the README covers tccutil reset.
